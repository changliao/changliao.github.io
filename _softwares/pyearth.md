**PyEarth** is a lightweight Python package designed to simplify routine scientific analysis, spatial data manipulation, and visualization workflows in Earth system sciences. Inspired by the utility concepts of the classic IDL Coyote library, PyEarth provides intuitive utilities for geospatial data, matrix conversions, and plotting.

### Installation
You can install PyEarth via conda-forge:
```bash
conda install -c conda-forge pyearth
```
Or via pip:
```bash
pip install pyearth
```
