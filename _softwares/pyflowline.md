**PyFlowline** is a Python package designed for mesh-independent river network generation and topological operations. It serves as a foundational component for unstructured hydrologic models, allowing river networks to be mapped onto arbitrary meshes (such as MPAS Voronoi meshes, hexagons, triangles, and lat-lon grids) with topologically consistent connectivity.

### Installation
You can install PyFlowline via conda-forge:
```bash
conda install -c conda-forge pyflowline
```
Or via pip:
```bash
pip install pyflowline
```
